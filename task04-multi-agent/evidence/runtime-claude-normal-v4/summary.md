- 四、常見詐騙話術辨識——「穩賺不賠」「保證回本」「老師帶單」「內部漏洞」「投資型娛樂城」、交友軟體引導下注等典型手法：這句用引號列出受管制詞「穩賺不賠」。按 CLAIMS 規則，就算是拆穿詐騙話術、加了引號，這個詞也不能出現在大綱裡，控制器會直接用字面比對擋下。Planner 的說明提到全文不寫實測、勝率等數據，這點成立，但沒有處理這個詞。本段揭露詐騙話術的方向沒問題，只需改掉這個字面用語。；建議：把「穩賺不賠」換成不含受管制詞的說法，其他話術保留。例如改成：「四、這5種話術一出現就該警覺——宣稱『零風險、只賺不賠』、「保證回本」「老師帶單」「內部漏洞」「投資型娛樂城」、交友軟體引導下注；並說明莊家優勢讓長期期望值為負，所以任何穩定獲利的說法都不可信。」這樣保留了數字和辨識話術的閱讀價值，也補上一般機率常識，讓讀者看懂為什麼不可信。（CLAIMS）
