## 第 1 輪
Planner 標題：娛樂城推薦前必看：出金卡關、個資與法律風險5大查核
Planner 說明：第1輪，還沒有 Auditor 意見。我的策略是：標題保留「娛樂城推薦」這個主關鍵字，吸住搜尋意圖，再用「必看」「出金卡關」「5大查核」這些痛點和數字拉點擊率，標題約25字，符合32字以內。內容整篇轉成風險查核，不列名單、排名、機率或實測，也不宣稱任何平台安全或合法。引用的法條、熱線只用我確定存在的：刑法第266條、第268條、洗錢防制法（沒寫條號）、165、1925，刑責細節交由讀者查法條原文或問律師，避免寫錯。如果 Auditor 認為標題的「推薦」還是有導購暗示，我可以改成「娛樂城推薦可信嗎？出金卡關與法律風險5大查核」，關鍵字還在，比丟掉通過機會好。
判定（只有 MUST 退回）：退回
Auditor 回應：標題、各查核小標和 FAQ 都可以接受：「推薦」關鍵字、「5大查核」數字和痛點都保留，內容要點裡的話術也有標明是廣告說法。現在不能接受的只有查核5把「代理招攬」直接歸到刑法第268條，請改成個案判斷的寫法再送審。
- MUST M1-1（Auditor，LEGAL）提供場所或聚眾賭博、代理招攬等行為，涉及其他更重的規定（如刑法第268條相關規定）。：依給定來源 TW-CC268，第268條處罰的是「意圖營利，供給賭博場所或聚眾賭博」，條文沒有提到代理、招攬或導流，這些人怎麼論罪要看個案。原句把「代理招攬」直接套進第268條，等於替法條擴大了適用範圍，違反 LEGAL「來源不足則標未知」。這會造成兩種誤解：有人以為只要當代理就一定適用第268條的重刑；反過來，也有人在查到條文沒寫「代理」後，以為推廣、拉人完全不必負責，結果低估了被當成共犯或觸犯其他規定的風險。Planner 說法條只引用自己確定存在的，這個做法是對的，但條文存在不代表能延伸到條文沒寫的行為。；建議：拆成兩句：「意圖營利，供給賭博場所或聚眾賭博，屬刑法第268條的處罰範圍，刑度比單純賭博更重。」以及「替平台當代理、招攬或導流的人是否適用、怎麼論罪，屬個案判斷，請以司法實務與律師意見為準，不能當作沒有責任。」
- SHOULD S1-1：標題可以考慮用 Planner 提的備案「娛樂城推薦可信嗎？出金卡關與法律風險5大查核」。「推薦前必看」在搜尋預覽裡，容易被讀成「查核完就能放心挑一間」的選前清單；改成疑問句，主關鍵字和數字都還在，也更符合內文「不提供名單」的定位。
- SHOULD S1-2：在「已經儲值或出金卡關」或查核4加一個能自己查證的步驟，例如到 165 全民防騙網查詢已公布的可疑網站或 LINE ID，並說明怎麼確認是官方網址。這樣讀者拿到的就不只是警訊清單，還有能馬上做的查證動作。

## 第 2 輪
Planner 標題：娛樂城推薦可信嗎？出金卡關、個資與法律風險5大查核
Planner 說明：M1-1（查核5把代理招攬直接歸到第268條）：同意，照 Auditor 的方向拆成兩句。第268條只寫它條文涵蓋的「意圖營利，供給賭博場所或聚眾賭博」，刑度比單純賭博重；代理、招攬、導流另外寫成「是否適用、怎麼論罪屬個案判斷，以司法實務與律師意見為準，不能當作沒有責任」。這樣不會擴大法條範圍，也不會讓讀者以為拉人不用負責。我沒有替代理招攬寫上任何罪名或刑度。另外在 FAQ 補了一題「只是幫忙拉人、當代理，會有事嗎？」，答法和內文一樣是個案判斷。這是很多人真的會搜的問題，也能留住讀者。

保留的點擊要素：主關鍵字「娛樂城推薦」放在標題最前面；痛點「出金卡關」、資安切入點「個資」、「法律風險」都還在；數字「5大查核」保留；標題改成疑問句，引起好奇心。標題約25字，在32字以內。各查核小標、出事處理和 FAQ 的結構不變，只修正被指出的那一句，其他內容沒有因此改得保守。新增的165查證步驟反而讓文章多了「現在就能做」的實用價值。

查證邊界：165全民防騙網、.gov.tw 網域都是確定存在的公開資訊。我沒有寫具體查詢欄位或功能名稱，以免寫錯。也特別寫明「查不到不等於安全或合法」，避免查證步驟被讀成一種替平台背書的方式。
判定（只有 MUST 退回）：通過
Auditor 回應：M1-1 的改寫我接受：第268條只寫條文涵蓋的「意圖營利，供給賭博場所或聚眾賭博」，代理、招攬、導流改成「屬個案判斷，不能當作沒有責任」，FAQ 的答法也一致，沒有擴大法條範圍，也沒有讓讀者以為拉人不必負責。新標題、165 查證步驟，以及「查不到不等於安全或合法」的寫法都合規。點擊要素也都保留，包括主關鍵字、出金卡關、個資、5大查核和疑問句。這一版沒有退回事項，兩則建議是選填的。
- SHOULD S2-1：可以加一則一般機率常識，放在查核1或FAQ都可以，例如「為什麼常聽到有人贏錢？」：賭局有莊家優勢，長期期望值是負的，短期贏錢不代表勝率高，也不代表平台一定讓你出金。這呼應原題「誠實揭露勝率」的方向，又不需要任何平台數據或RTP數字；讀者也能理解帶單、贏錢截圖為什麼不可信。
- SHOULD S2-2：文末可以放一張可以截圖保存的「5大查核速查表」，每項寫一個警訊和一個馬上能做的動作，例如「出金前要先付解凍費→不付款，打165」，方便在手機上快速對照，也比較容易分享。
- Planner 對 S1-1：adopt，Auditor 說得對。「推薦前必看」的意思是看完就能去挑，但內文第一段就說了在台灣參與線上賭博本身可能違法，這個標題等於承諾了文章不會給的東西，讀者點進來發現沒有名單，可能馬上離開。疑問句「娛樂城推薦可信嗎？」主關鍵字還在最前面，同樣能吸引好奇點擊，也跟內文一致。我在備案上多保留了「個資」，維持需求中的資安切入點，標題約25字。
- Planner 對 S1-2：adopt，這是讀者真正能馬上做的事，加強了文章的閱讀價值。我放在查核4，也在出事處理段落提一次，並說明怎麼確認官方網址（.gov.tw，自己輸入網址，不點別人傳來的連結）。另外加上「查不到不等於安全或合法」，再配一題 FAQ，避免讀者把查證結果當成平台的保證。
