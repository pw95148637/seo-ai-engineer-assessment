## 第 1 輪
Planner 標題：娛樂城推薦可信嗎？出金、資安、法律風險7大查核重點
Planner 說明：我的策略：保留「娛樂城推薦」這個主關鍵字，用來接住搜尋需求，但把文章定位改成「讀者自己做查核」，而不是替平台排名。這樣可以兼顧點擊率和不誤導，也讓 Auditor 比較容易通過。標題有三個吸引點擊的元素：疑問句「可信嗎？」、數字「7大」、具體收益「出金、資安、法律風險查核重點」，全長約25字，在32字以內。小標也沿用痛點句型（例如「出不了金？」「HTTPS 不等於安全」）來提高停留時間，並適合用來爭取精選摘要。內容方面：沒有寫任何平台名稱、排名、出金率、機率、實測或審查結果；法律部分只引用刑法第266條的一般性質，也沒有寫具體罰金數字，以免出錯，並提醒讀者以全國法規資料庫的最新條文為準、本文不是法律意見。文中提到的165反詐騙專線與1925安心專線，都是台灣公開的求助管道。如果 Auditor 認為標題裡的「推薦」可能被理解成背書，我可以接受改成「娛樂城推薦文可信嗎？」或在副標寫明不推薦平台，關鍵字仍保留。
判定（只有 MUST 退回）：退回
Auditor 回應：接受：標題「娛樂城推薦可信嗎？」是疑問句，搭配查核定位，不構成背書，不必改成「推薦文」。7大查核、出不了金的4個步驟、165和1925的求助資訊都保留；沒有虛構實測、排名或數據，這部分通過。仍不能接受：快篩表和查核3、4把查核寫成「儲值前」的放行步驟，查核6還教讀者用次要的帳戶或信用卡儲值。這些等於暗示做足功課就能參與，必須改成辨識詐騙的定位。另外，程式擋下的「保證出金」也要一併刪掉。
- MUST M1-1（程式，CLAIMS）常見的推薦來源有：推廣分潤（邀請碼、專屬連結）、業配、社群或私訊招攬。可以留意的警訊：排名沒有公開評分標準、通篇只講優點、強調「限時」「保證出金」、要你加 LINE 或 Telegram 才給連結。提醒讀者：寫了「實測」卻沒有可以查證的過程與證據，不應該當成依據。：含零容忍詞彙「保證出金」；規則禁止此詞出現在標題與大綱，引號、疑問或拆穿語境也不例外；建議：刪除此詞，改用不含此詞的說法表達同一重點
- MUST M1-2（Auditor，LEGAL）把前面7個查核重點整理成是非題清單，例如「出金條款我找得到、也看得懂嗎？」「收款帳戶是個人帳戶嗎？」「有人要我先付費才能出金嗎？」只要有任何一題亮紅燈，就建議不要儲值。同時提醒：如果覺得自己難以控制投注行為，可以撥打衛福部1925安心專線尋求協助。：「只要有任何一題亮紅燈，就建議不要儲值」反過來讀就是「7題都過關就可以儲值」。小標「儲值前的7題快篩」也把這張表包裝成下注前的放行檢查。讀者會以為條款看得懂、收款帳戶不是個人帳戶，就算安全、可以參與。但依刑法第266條，透過網路賭博財物本身就有刑責風險，平台條件再好也不會變合法，讀者可能因此儲值，同時承擔財物損失和刑事風險。Planner 說整篇定位是「讀者自己做查核」，這個方向沒問題，但這一段的判斷邏輯等於替「通過查核的平台」放行，抵銷了前面的法律提醒。；建議：保留「7題快篩」的數字和是非題形式，但把用途改成「辨識推薦文與平台話術的警訊」，不再當成儲值前的檢查。例如小標改為「一張表自我檢查：看穿娛樂城推薦文的7題快篩」，結論寫成：「亮紅燈越多，越可能是詐騙；就算全部沒亮燈，也不代表平台可信或在台灣合法，網路賭博財物仍有刑責風險。」1925安心專線的提醒保留。
- MUST M1-3（Auditor，LEGAL）建議做法：不要在這類平台使用和其他服務相同的密碼，避免用主要的銀行帳戶或主要的信用卡。：這句等於在教讀者「怎麼比較安全地註冊和付款」：換一組密碼、改用次要的帳戶或信用卡來儲值。讀者會以為風險可以靠帳戶分流壓低，等於拿到一套參與步驟。這屬於鼓勵投注的操作，也弱化了刑責風險；用次要帳戶跟境外平台金流往來，還可能讓帳戶被當成異常交易或警示帳戶，跟查核5的提醒互相矛盾。；建議：改成「不註冊、不提供」的防護建議，保留資安實用性。例如：「建議做法：不要下載來路不明的 APK、不要上傳證件和自拍；如果已經提供，請立刻更換其他服務的同組密碼、通知銀行留意異常交易，必要時撥打165。」
- MUST M1-4（Auditor，LEGAL）教讀者在儲值前先找出並讀懂這些條款：流水（投注量）倍數要求、最低與最高出金金額、出金次數或時間限制、身分驗證（KYC）在什麼時候要求、平台保留凍結帳戶或沒收獎金的權利。：「在儲值前先找出並讀懂」把讀條款寫成儲值前的準備步驟，暗示看懂條款以後就能理性參與。讀者可能以為只要做足功課，儲值就是合理的消費決定，忽略網路賭博財物在台灣本身的刑責風險。這和快篩表是同一類問題，所以用同一個方式改。；建議：5個條款的內容保留，只改定位：「教讀者辨識推薦文和平台常拿來卡出金的5種條款：……；這些條款常被用來拒絕出金，看懂它們是為了認出陷阱，不代表讀懂了就可以放心儲值。」小標「出金條件藏在哪？先看懂這5個條款」可以保留。
- MUST M1-5（Auditor，LEGAL）提醒：優惠越誇張，越要先讀條款。：「越要先讀條款」暗示讀完條款就可以接受優惠、開始儲值，跟查核3一樣是理性參與的寫法。讀者可能把高額首儲加碼當成值得研究的機會，而不是誘導儲值的警訊，結果投入資金、面臨獎金被取消和法律風險。；建議：改成警訊式提醒，保留原本的反差句型：「提醒：優惠越誇張，越可能是誘導你儲值的話術；條款再清楚，也不會讓網路賭博在台灣變合法。」
- SHOULD S1-1：FAQ「有沒有『合法』的娛樂城推薦？」的答案目前只寫「說明台灣法律背景」，太含糊。FAQ 常被單獨擷取成摘要，建議直接寫：「依刑法第266條，在台灣透過網路賭博財物可能受罰；境外牌照或年滿18歲都不等於在台灣合法，個案請諮詢律師。」這樣更能回答讀者的搜尋意圖。
- SHOULD S1-2：查核7可以補充：刑法第266條「暫時娛樂物」的例外範圍很窄，通常不包括現金或可以換回現金的點數。這樣可以避免讀者誤以為小額下注就沒事，也讓法律段落更具體、更好查證。
