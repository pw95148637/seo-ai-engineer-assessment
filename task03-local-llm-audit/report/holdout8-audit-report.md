## 共同偏差

1. **YMYL 依主題觸發**：ID 3、8、12 的 adapter 理由分別是「主動推薦娛樂城」「未說明此貸款可能涉及高風險」「文章提及『娛樂城』」，都是 prompt 明文排除的「只談高風險主題或沒列全部風險」。模型看到賭博或貸款主題就觸發，沒有先確認原文是否主動給出保證、否認後果或引導參與。
2. **語意反讀**：ID 17 把「絕不會詢問驗證碼」這種提高警覺的否定句讀成否認風險。
3. **等級膨脹**：8 筆中 7 筆的 severity 高於主判讀，沒有一筆偏低；`SEO_FALSE` 與「引導參與」依 prompt 是 major，模型給 critical。分數因此整體偏低（平均 −27）。
4. **照抄卡片與定義**：ID 2、3、1 的理由大段重複 TW_266 卡片原文或 prompt 定義，看起來有依據，實際沒有說明原文哪一句、為何構成缺失。
5. **堆疊辨識受主題干擾**：train ID 16 的重複關鍵字 adapter 與 base 都抓得到，賭博主題的 ID 3 則兩者都漏掉。

## 檢查器與報表的注意事項

- **ID 12 的 `hard:FALSE_EXPERIENCE` 是檢查器誤報**：`scripts/selfcheck.py` 的 SELF_REPORT 正規式只依 train12 設計，列了實測、心得、體驗等詞，沒有「註冊」「感受」，所以沒認出「我實際註冊後最直觀的感受」是自述。模型這筆的經驗判斷是對的。AutoFlags 是啟發式提示，不是準確率。
- **風險揭露檢查器**：holdout 的 21 句建議分別交給凍結版與修正版 `removes_risk`，判定完全相同，都沒有被判為刪除風險揭露；凍結後修正檢查器不影響 holdout 結果。這個檢查只看「風險、警示」等字，抓不到 base 在 ID 17 削弱資安警語的建議。
- **`audit_report.html`**（Kaggle 產出）可直接開啟，可排序、篩選，含 base 對照表；它不含參考判斷與逐筆判定。含參考對照的版本是 `report/holdout8-audit.html`。
