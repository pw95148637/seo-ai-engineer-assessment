# 來源與證據層級

- 官方 Hermes 固定版本：https://github.com/NousResearch/hermes-agent/tree/311155fade43d1993ea968909a2ad36762345bbc
- 該版本工具擴充指引：https://github.com/NousResearch/hermes-agent/blob/311155fade43d1993ea968909a2ad36762345bbc/website/docs/developer-guide/adding-tools.md ，保存於 evidence/official-adding-tools.md。
- 該版本模型供應商與登入：https://github.com/NousResearch/hermes-agent/blob/311155fade43d1993ea968909a2ad36762345bbc/website/docs/integrations/providers.md ，保存於 evidence/official-providers.md。只是官方支援路徑，不代表帳號已授權。
- Robots Exclusion Protocol（控制器的 robots.txt 規則依據）：https://www.rfc-editor.org/rfc/rfc9309
- https://2030.tw/robots.txt 、https://2030.tw/sitemap_index.xml ：開發初期直接請求皆為 HTTP 200，headers、body 與雜湊保存在 evidence/（robots-*、sitemap*）。Sitemap 共六個子索引，不能推導頁數、內容品質或流量。
- 原題與指定文件的 SHA-256：evidence/spec-hashes.json（原題全文不放在公開 repo）。
