兩組都沒有學到錯誤或過度推廣的內容，也沒有學進網頁文字或網頁上的指示。

帳本在 5 次中另外記下 3 條候選失敗經驗，沒有一條達到採用門檻（同一做法在 2 個以上的 run 失敗），所以都沒有交給模型：「含 `site:` 的搜尋沒有結果」在 L1 同一次就遇到成功的 `site:` 搜尋而撤銷；「不含 `site:` 的搜尋沒有結果」在 L2 遇到反例撤銷，L5 又失敗一次後回到候選；「站外讀取遇到不支援的內容類型」停在候選（`ledger-frozen.sqlite` 的 `lesson_history`）。

**為什麼原生 6 次回顧都完成，最後只留 1 個 skill、0 條記憶**（依 `steps.json` 的回顧紀錄、每步儲存 `native/<step>-attempt1-after/` 與 transcript）：

1. **每次回顧都選擇改 skill。** N1 的回顧建立 `public-evidence-seo-research`，NF、N2–N5 的回顧都是修補同一個 skill（動作紀錄：created 一次、patched 五次；結果類型 6 次都是 `skill`）。skill 由 4,472 位元組長到 7,759 位元組。NF 那次 agent 自己也呼叫了 `skill_view` 與 `skill_manage`，把團隊署名的審查標準寫進 skill，之後回顧再補一條「只是要求套用標準時不重新研究網站」。
2. **Hermes 的提示把這類經驗導向 skill，而且要求寫成通用規則。** 固定版本的記憶指引寫「Skills come first」，記憶是「the narrow exception for facts that apply to EVERY session regardless of task」，並說「A fact stale within a week belongs in session history; procedures and workflows belong in skills」（`agent/prompt_builder.py`）。回顧提示要求 CLASS-LEVEL 的 skill，「the rule must stand without the incident behind it」，不記一次性的任務敘述（`agent/background_review.py`）。
3. **所以學到的是「怎麼研究」，不是「目標頁在哪裡」。** 凍結的 skill 沒有出現 2030.tw 或 `/wordcup/`，沒有任何網址。原生組因此沒有比第 1 次更快找到目標頁（7–9 次呼叫，與對照相同）。帳本的發現路徑正好是「這個網站的目標頁在哪裡」，並由控制器在使用前重抓確認，所以第 2 次起 1 次呼叫就讀到。
4. **成本上升的來源**：
   - Hermes 的 memory 與 skills 工具說明、記憶指引與 skills 索引讓每次模型呼叫的固定輸入變大，第一次模型呼叫的輸入在 N1 是 5,497、N5 是 5,756 tokens，對照組是 3,844。
   - 第 2 次起每次先用 `skill_view` 讀進整個 skill（N5 讀到 7,918 字元），之後每次模型呼叫都重送。
   - skill 要求更多查核（類別篩選頁、對比樣本、長尾頁），每次讀頁 7–8 頁、主張 13–15 項，對照組是 5 頁、11–12 項。
   - 品質沒有因此提高：五份報告的盲評覆蓋分數都是 7，缺陷都是 0。

人工審查標準在兩個學習組都進入了學到的內容，但無法從報告看出效果：對照組的報告也常寫「編輯部署名不是具名作者」。

- **訂閱用量**：原生每次 3–4 點、帳本與對照每次 2–3 點，方向與主指標一致，但只有整數百分點，不當證據。

## 限制

- 量的是第 5 次，不是原題的第 10 次；每組每個點只跑一次。對照範圍只有 5 次，品質部分只有 C1、C5 兩次，所有覆蓋分數都是 7，品質維度沒有鑑別力。
- 帳本的優勢集中在「這個網站的目標頁在哪裡」，換到沒有目標詞頁的保留站就沒有可用的發現路徑；保留站只證明兩種學習都沒有造成傷害。
- 帳本 lesson 的呈現方式在 v0.6–v0.7 由人看過 trace 後改寫過；Hermes 用自己的提示，沒有調整。發現路徑讓模型直接讀控制器已重抓的頁面，這段不花模型成本，原生組沒有對應的路徑。
- 研究 prompt 明寫照 research_status 的 lessons 行動，原生組的 memory 與 skill 只靠 Hermes 自己的 system prompt。
- 回顧被強制每次執行，比 Hermes 預設排程頻繁；curator（以天為單位整理 skill）不在測試內。
- 站外研究仍受限於免金鑰搜尋：所有報告的站外部分只有出站連結與陰性樣本。
- 報告與學習內容的風格可能讓盲評者猜到組別；盲評者只對分數盲。學習內容分類的分組說明是中性的，但證據路徑名稱會透露組別。
- 人工審查標準的效果無法從報告分辨，因為對照組也常寫出相同的判斷。
